## 动态数组
- 动态数组在 Rust 中存在，可以使用 `vec` 关键词进行创建
```
fn main (){
	let mut arr = vec![1,2,3];
	arr.push(4);
	println!("{}",arr[2]);
}
```
- 动态数组是不定长类型，默认实现是存放于[[栈和堆#堆|堆]]中

## 动态元组（Tuple）
- 元组是固定长度、固定类型的结构，**编译时大小已确定**，无法动态增删元素，所以 Rust 中并无直接可以使用的动态元组
- 可以使用枚举包裹数据类型来完成动态元组的功能
```
enum DynamicData {
    Int(i32),
    Text(String),
    Float(f64),
}

let mut dynamic_tuple: Vec<DynamicData> = Vec::new();
dynamic_tuple.push(DynamicData::Int(42));     // 添加整数
dynamic_tuple.push(DynamicData::Text("Hi".into())); // 添加字符串
```
