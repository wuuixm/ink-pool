#### 对比栈和堆两种内存管理模型的区别
---

##### **tags:** #笔记 
##### **2025-08-16**

---
## 栈
- 栈是一块连续的内存区域，有编译器进行管理
- 栈的空间大小是**有限的**，但分配和释放的速度很快，通过指针进行移动
- 栈中放的是编译期就已经**确定大小**的数据类型，比如基本类型，定长数组，定长元组以及普通结构体，枚举等
- 借用 (`&str`) 或切片也存放于栈中，是一个指针加一段固定长度
- Rust 中**默认数据**存放于栈上
- 各种容器 (`String`、`Vec<T>` 等) 的**控制块**(指针、长度、容量) 也存放于栈中，即变量名与数据是分开的，虽然像是 `String` 这样的不定长类型需要放在堆中，但是本质是创建了一个指向数据的指针，指针本身放在栈中，指向放于堆中的数据 ^01 ecf5

## 堆
- 堆是一块由操作系统统一管理的动态内存池
- 堆的空间大小是**较大的**，但分配和释放需要调用内存管理器，开销比栈大
- 堆中存放的是编译期**大小不确定**，运行时大小可变的数据比如 `String` 的内容，`Vec<T>` 的元素，`HashMap<K,V>` 的键值对等，但需注意，这些变量是存放在栈中的，其内部包含一个指针，指向它们在堆上分配的实际数据
- Rust 中所有的大小未知的数据类型都应该存放于堆中，比如链表，这是一个通过递归创建的经典数据结构，其大小显然是未知的，因而需要放在堆中
- Rust 中，可通过**智能指针**(`Box`) 将默认放在栈上的内容存放于堆中
```
struct Point {
    x: i32,
    y: i32,
}

fn main() {
    let p1 = Point { x: 10, y: 20 };
    println!("栈上的 Point: x = {}, y = {}", p1.x, p1.y);
    
    let p2 = Box::new(Point { x: 30, y: 40 });
    println!("堆上的 Point: x = {}, y = {}", p2.x, p2.y);
}
```

## 栈 vs 堆

| 特性          | 栈 (Stack)                                    | 堆 (Heap)                                                                     |
| ----------- | -------------------------------------------- | ---------------------------------------------------------------------------- |
| **分配方式**    | 编译器自动管理，函数调用时进栈，返回时出栈                        | 程序员/容器显式申请，运行时由内存分配器管理                                                       |
| **内存区域**    | 一块连续的内存，增长/收缩只移动指针                           | 一块大内存池，分配/释放需要查找合适的块                                                         |
| **大小**      | 较小（几百 KB ~ MB）                               | 较大（取决于系统可用内存）                                                                |
| **分配/释放速度** | 极快（O (1)）                                     | 较慢（O (n) 查找 + 元数据维护）                                                          |
| **生命周期**    | 跟随作用域自动结束                                    | 必须手动释放（C）或由智能指针/GC 管理（Rust/Java）                                             |
| **适合存放**    | 小的、固定大小的数据                                   | 大的、可变大小的数据                                                                   |
| **Rust 示例** | `let x: i32 = 5;` `let p = Point {x:1,y:2};` | `let s = String::from("hi");` `let v = vec![1,2,3];` `let b = Box::new(42);` |
