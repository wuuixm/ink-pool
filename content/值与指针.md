## 值传递与所有者变量
**1. C 中的值传递**
- 在 C 中，变量的赋值与函数传参是一种 `copy` 类型的复制，即一块内存中的数据可以有许多个变量与之对应
```
int main(void) {
    int x = 42;   
    int y = x;  
    printf("x = %d, y = %d", x, y);// 可正常输出
    return 0; 
}
```
**2. Rust 中的所有者变量** 
- 在 Rust 中，存在[[所有权机制]]，变量的赋值与函数传参是一种 `move` 类型的复制，即一块内存中的数据只可以有一个变量与之对应
```
fn main(){
	let x = String::from("abc");
	let y = x;
	//println!("x = {x}, y = {y}")// 编译错误，x的所有权已经转移给y了
}
```
- Rust 中规定每块数据在任意时刻只能有一个变量作为它的所有者，当所有者变量离开作用域时，Rust 会自动释放那块内存，变量的复制为 `move` 类型，即所有权的转移，而失去所有权的变量失效，不能使用
- 在 Rust 中，**所有的变量**本身放于栈中，[[栈和堆#^01ecf5|数据存放于堆中]]
- Rust 的所有权机制并不包括基础类型，如 `int`，`char`，`double` 等
```
fn main(){
	let x = 42;
	let y = x;
	println!("x = {x}, y = {y}")// 正常输出
}
```

## 指针传递与借用
**1. C 中的指针传递**
- 指针传递，就是将需要传递的数据的内存地址交给函数，函数的行为影响的是作为参数的那块内存中的数据
```
void add_one(int *p) {
    *p = *p + 1;
}

int main() {
    int x = 10;
    printf("Before: x = %d\n", x);
    add_one(&x);
    printf("After:  x = %d\n", x);
    return 0;
}
```
**2. Rust 中的借用**
- 借用的原理与**指针**非常相似，在 Rust 中，借用就是临时借用数据的使用权而不拿走所有权
- 借用存放于栈中
- 可变借用 `&str`
```
fn add_one(x: &mut i32) {
    *x += 1;
}

fn main() {
    let mut a = 10;
    add_one(&mut a);
    println!("a after add_one: {}", a);
}
```
- 不可变借用 `&mut str`
```
fn print_value(x: &i32) {
    println!("Value: {}", x);
}

fn main() {
    let a = 10;
    print_value(&a);
    println!("a is still: {}", a);
}
```
- 在任一时间，可以存在多个不可变借用，至多存在一个可变借用，不可变借用与可变借用不能同时存在
```
fn main() {
    let mut x = 10;
    // 多个不可变借用
    let r1 = &x;
    let r2 = &x;
    println!("r1 = {}, r2 = {}", r1, r2); // 可以同时存在
    // 可变借用（此时不能再有不可变借用）
    let r3 = &mut x;
    *r3 += 5;
    println!("r3 = {}", r3);
    // println!("r1 = {}", r1); // 编译错误：r1 已经失效，不能和可变借用同时存在
}
```
