#### 函数式编程中使用高阶函数与传统函数调用的区别
---

##### **tags:** #笔记 
##### **2025-08-20**

## 高阶函数
- 高阶函数就是在函数式编程中，将函数本身作为参数进行传递
```
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn display(func: fn(i32, i32) -> i32, a: i32, b: i32) {
    println!("{}", func(a, b));
}

fn main() {
    let x: i32 = 1;
    let y: i32 = 2;
    display(add, x, y);// add函数作为参数传入了另一个参数
}
```

## 高阶函数与传统函数调用的对比
**1. 控制权不同**
- 传统函数调用中，函数 A 主动决定调用函数 B，完全掌握调用的时机
```
fn A() {
    B();
}
```
- 高阶函数中，函数 A 接收一个函数作为参数，将部分逻辑的控制权交给外部，由调用者注入行为
```
fn A(f: fn()) {
    f();
}

fn main() {
    A(|| println!("这是输出")); 
}
```
**2. 解耦与复用性**
- 传统函数中函数 A 与 B紧耦合。若想改变 A 的行为（如替换 B 为 C），需修改 A 的代码。
- 高阶函数中通过传递不同函数，复用 A 的逻辑框架，实现不同行为，无需修改 A
```
A(|| println!("这是输出1"));
A(|| println!("这是输出2"));
```
